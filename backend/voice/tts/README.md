# Text-To-Speech (TTS) Subsystem

The Text-to-Speech Engine converts text strings generated by the Auralis assistant back into natural-sounding voice signals. It is fully decoupled from the core assistant logic and operates independently.

## Architecture

```
ExecutionResult ──> Response Generator ──[Text String]──> TextToSpeech ──[Audio Bytes (WAV/MP3)]──> Audio Output (Speaker)
```

- **TextToSpeech**: Coordinative engine that chooses the synthesis backend. Prefers online `edge-tts` (Microsoft Neural voices) and falls back to local/offline `pyttsx3`. Returns a `SpeechResponse`.
- **VoiceManager**: Loads available system/API voices, configures default speakers, and registers custom voice profiles.
- **AudioOutput**: Operates a thread-safe playback queue on a background worker thread. Plays WAV files in-memory using `winsound`, plays MP3 files natively via Windows MCI (`mciSendString`), and controls immediate stop/interruption.

## Models

Refer to [models.py](file:///c:/Users/Vishal%20S%20Naik/MyProjects/Auralis-voice-file-manager/backend/voice/tts/models.py):
- `TTSConfiguration`: Customizes preferred engine, voice IDs, rate (speed), volume, and target language.
- `SpeechResponse`: Standard return structure capturing audio binary bytes, success markers, latency stats, and exception notes.

## Usage

### Simple Text Announcing

```python
from voice.tts import TextToSpeech

tts_engine = TextToSpeech()

# Speaks out text, blocks calling thread until playback finishes (default)
tts_engine.speak("Auralis initialization completed successfully.")
```

### Queueing & Background Speaking

```python
from voice.tts import TextToSpeech, TTSConfiguration

# Use pyttsx3 fallback directly
config = TTSConfiguration(engine="pyttsx3", rate=160, volume=0.8)
tts_engine = TextToSpeech(config)

# Speak multiple sentences without blocking (wait=False)
tts_engine.speak("Processing file conversion.", wait=False)
tts_engine.speak("Conversion succeeded.", wait=False)

# Let background queue finish or interrupt immediately if needed
# tts_engine.audio_output.stop()
```

### Direct Buffer Generation

```python
from voice.tts import TextToSpeech

tts_engine = TextToSpeech()

# Generate bytes without playing immediately
response = tts_engine.synthesize("Welcome back, user.")

if response.success:
    audio_bytes = response.audio_data  # MP3 or WAV binary bytes
    print(f"Synthesized voice buffer (latency: {response.latency:.2f}s)")
```
