# Tiered Memory System

## Purpose of this Module
Stores and retrieves context across sliding sessions, semantic indexes, and preferences.

## Future Responsibility
Tracking user preferences, retaining short-term chats, embedding long-term sessions, and managing code indices.

## What Should Belong Here
- Short-term buffers, vector DB connections, semantic memory loaders, workspace indexers.

## What Should NOT Belong Here
- Speech recorders, process managers, command controllers.
