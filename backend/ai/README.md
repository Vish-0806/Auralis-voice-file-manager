# AI Brain Engine

## Purpose of this Module
Handles NLP parsing, intent mapping, reasoning loops, and prompt configurations.

## Future Responsibility
Integrating local/cloud LLM instances, compiling dynamic context templates, selecting tools, and analyzing security limits.

## What Should Belong Here
- Prompt building files, reasoning loops, intent classifiers, entity parsing utilities, tool selectors.

## What Should NOT Belong Here
- Web servers (FastAPI routers), direct filesystem operations, audio hardware libraries.
